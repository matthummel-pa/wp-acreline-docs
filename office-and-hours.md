# Office and hours

Site-wide identity lives in **Appearance → Customize → Identity**. Editing a theme file does not change these values. They are stored with the WordPress site.

Set:

- Brokerage or agent name
- Phone (the concept demo uses `(555) 010-0455`; use your real number on a live site)
- Email
- Street address
- Hours
- Social profile links

The header, footer, and contact page read these values. Color choices are separate. See [Branding and styles](branding-and-styles.md).

Acreline does not sync hours to a reservation product. Showings are requests stored as posts. See [Showings](showings.md).
