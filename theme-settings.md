# Theme Settings

Open **Appearance → Acreline Settings**. You need the Administrator role (`manage_options`). The screen shows the theme version and a link to **Appearance → Acreline Support**.

Settings are stored in the `acreline_settings` option. They travel with the site, not with a theme update. Updating the theme does not reset them.

## Tabs

| Tab | Use it for |
| --- | --- |
| Listings | Grid columns, card fields, and single-listing sections. See [Listings](listings.md). |
| Agents | Profile sections. See [Agents](agents.md). |
| Bookings | Optional fields on the showing form. See [Showings](showings.md). |
| Market | Market figures shown as sample stats. On a live site, replace the concept numbers with figures you are allowed to publish. |
| Compliance | Fair-housing and disclaimer copy the theme can show. Read it and replace the concept text with language your brokerage uses. |
| Labels | Words the theme uses for townships and similar labels. Demo values stay `Cumberland`, `Straban`, and `Franklin`; the public labels are North Ridge, Mill Creek, and Oak Hollow until you change them. |
| General | Switches that are not specific to one post type, including color-style options shared with the Customizer. |

Save on the tab you are editing. WordPress returns you to that tab and shows “Settings saved”.

## What belongs in the Customizer instead

Phone, address, hours, social links, and the site name belong in **Appearance → Customize → Identity**. See [Office and hours](office-and-hours.md) and [Branding and styles](branding-and-styles.md).

## License screen

After Freemius is configured, the license and account screen is also under **Appearance**. It is separate from Acreline Settings. See [License and updates](license-and-updates.md).
