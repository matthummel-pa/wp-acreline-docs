# Blocks

Pages and posts can use the blocks registered by the theme. They are registered from the theme and show up in the block inserter when you edit a page or a post.

**Tools → Block Generator** can create an additional block without writing the registration by hand. **Tools → Migrate to Blocks** copies older page fields into block content. You do not need that tool on a new site that never used the old field boxes.

Listings, agents, and bookings do not become blocks. Keep using their field boxes.

Full-site editing stays off. There are no theme templates to edit in the Site Editor.
