# Support

Email support is included with an active license (see [License and updates](license-and-updates.md)). The in-admin page is **Appearance → Acreline Support**.

## Include

- Site URL
- WordPress, PHP, and Acreline versions (**Appearance → Themes**, or the Acreline Settings header)
- What you clicked and what you expected
- A screenshot of the screen, with client names and phone numbers cropped out

## Do not include

- Passwords, license secret keys, API tokens, or GitHub tokens
- A client’s showing request, email, or phone number
- A full database export

Do not put that information in an issue on this public repository. This repository is for corrections to the guides. Open a pull request for a wrong step. For a problem on your site, use the support email from your receipt.

Security reports go to the address on [matthummel.com](https://matthummel.com/), not to a public issue.
