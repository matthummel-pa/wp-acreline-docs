# SEO

Acreline prints the document title, meta description, and Open Graph and Twitter tags itself. You do not need an SEO plugin for those tags. If you install one anyway, turn off its social tags so the page does not print two descriptions.

Set a specific title and excerpt on each page, post, listing, and agent. The homepage should describe the agent or team, not the concept-demo sentence.

The concept site is fiction. Do not point a real listing URL at a sample post and expect it to rank for a house that is not yours.

Sharing an image uses the featured image when one is set. Add a featured image to anything you expect people to paste into a chat or a social post.
