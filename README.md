# Acreline documentation

Setup guides and support for the **Acreline** WordPress theme. Acreline is a theme for solo real estate agents and small teams: homes, listings, showings, neighborhoods, and buyers and sellers. It is sold at [matthummel.com/shop](https://matthummel.com/shop/) and [matthummel.com/product/acreline/](https://matthummel.com/product/acreline/). The theme source repository is private. These docs are public so anyone can see how the theme works before buying.

Live concept demo: [acreline.matthummel.com](https://acreline.matthummel.com/). Listings, agents, phones, emails, and appointments on that site are sample fiction (`555` numbers, `@acreline-concept.test`).

## About this repository

Documentation only. No theme code, no license keys, and no API tokens. To fix a typo or an out-of-date step, open a pull request. For help with your own site, use [Support](support.md). Please do not post client names, showing requests, or site credentials in a public issue.

The concept demo’s “Get this theme” bar is a separate plugin used only on [acreline.matthummel.com](https://acreline.matthummel.com/). It is not part of the theme zip a buyer installs.
