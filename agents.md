# Agents

Agents are their own post type under **Agents**. The public agents page and each profile read those posts.

**Appearance → Acreline Settings → Agents** toggles profile sections:

- Performance stats (homes sold, volume, days on market)
- Social links
- Certifications and designations
- Awards
- Intro video link
- Team name
- Booking or calendar button

Put the office phone, email, and address in **Appearance → Customize → Identity** when they belong to the whole site. Put an individual agent’s photo, bio, and direct contact on the agent post.

Sample agents on [acreline.matthummel.com](https://acreline.matthummel.com/) are fictional. Do not publish them as real licensed agents.
